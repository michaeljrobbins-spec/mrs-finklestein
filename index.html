How to fix this
  1. Fully quit Chrome, then reopen it. Closing the window often isn't enough: on Windows, check the system tray for Chrome still running in the background; on a Mac, press Cmd+Q.
  2. In Chrome's Settings → System, turn on "Use graphics acceleration when available" and click Relaunch.
  3. Type chrome://gpu in the address bar. The WebGPU line should say "Hardware accelerated." If it says "Disabled" or "Blocklisted," updating Chrome and your graphics drivers usually fixes it.
  4. Close other tabs that use a lot of graphics (games, 3D maps, other AI demos), then reload this page.
